# Visão geral 
### 🧠 LOGIQuiz

O LOGIQuiz é uma plataforma interativa desenvolvida para ensinar lógica booleana de forma simples e prática.
O usuário pode escolher entre estudar a teoria ou praticar resolvendo questões, com feedback imediato e explicações detalhadas.

### 💻 Demonstração online:
👉 Acesse o LOGIQuiz no GitHub Pages

## 🚀 Funcionalidades

📚 Modo Teoria – o usuário pode visualizar conteúdos explicativos sobre lógica.

🧩 Modo Prática – o usuário escolhe o número de questões e o nível de dificuldade.

🔄 API própria que fornece as perguntas e alternativas localmente.

⏱️ Cronômetro que mostra o tempo gasto para responder o quiz.

📊 Cálculo da média de acertos.

❌ Feedback com explicação para respostas incorretas.

🧠 Questões reais, retiradas de provas de concursos.
